[2026-06-22] 추가: 창 닫혀도 24시간 구동 (원격 맥미니 + Claude CLI 헤드리스)

■ 결정 사항
- 두뇌를 "이 세션의 Claude" → "맥미니의 Claude Code CLical(구독 인증)"로 이전.
- 이유: 창 닫으면 이 세션은 사라져서 응답 불가. 24시간은 독립 프로세스 필요.
- 방식: ① Claude CLI 헤드리스 + 구독 (추가 API 과금 없음). 대상: 별도 원격 맥미니.

■ 추가로 만든 파일 (배포 꾸러미)
- bridge.py                          : 24시간 데몬. 텔레그램 롱폴 → claude -p 헤드리스 → 답장.
                                       세션 유지(--resume), 4096자 분할, /ping /reset 지원,
                                       409충돌·타임아웃·세션재개실패 자동 처리.
- telegram_config.example.json       : 설정 템플릿 (project_dir, claude_bin, permission_mode 추가)
- com.kakaostk.telegram-bridge.plist : launchd LaunchAgent 템플릿 (__PLACEHOLDER__ 치환식)
- SETUP_MACMINI.md                   : 맥미니 설치 가이드 (CLI설치→구독로그인→설정→테스트→데몬등록→절전해제)
- .gitignore                         : bridge.log 등 추가 제외

■ 어디까지 됐나
- 코드/문서 작성 + 문법검증 완료. 이 맥에서는 claude CLI 미설치라 실제 구동 테스트는 미실시.
- 이 Claude 세션의 자동 폴링 루프는 중단함(맥미니 데몬과 409 충돌 방지).

■ 다음에 할 것 (사용자가 맥미니에서)
- SETUP_MACMINI.md 따라 설치/구동. 핵심: 두 곳에서 동시 폴링 금지.
